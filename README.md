# sales-data-analysis
'Cleaning and analyzing sales data to uncover trends and insights.'

Tasks Done in this are :
- Data Cleaning: Processed the `Sales-Export_2019-2020.csv` dataset by handling missing values, formatting data types, and structuring records for analysis.
- Exploratory Data Analysis (EDA): Analyzed key metrics, including revenue distribution, order trends, product performance.
- Insights & Visualization: Evaluated patterns in the data to extract business.

- Repository Contents
- `chapter_appendix-tools-for-deep-learning/`: Folder containing the main analysis notebook (`jupyter.ipynb`).
- `Sales-Export_2019-2020.csv`: Raw sales dataset used for the project.
- `README.md`: Overview of the task and project structure.

Run code by following steps :
1. Open Google Colab or launch a local Jupyter environment.
2. Load `Sales-Export_2019-2020.csv` into your environment.
3. Run the notebook cells sequentially to execute the data processing and analysis code.
